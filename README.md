# Unified Mobility Centre

This repository simulates the backend data infrastructure for a national **Unified Mobility Centre (UMC)** in Malaysia. It is a simple reference for storing SQL queries and documentation around the project.

## Project Scope
The UMC integrates multimodal transport data, including:
- User demographics and subsidy eligibility.
- Stations and park-and-ride facilities.
- Routes with congestion scores.
- Feeder services and real-time road events.
- Journey logs.

The database schema is intended for experimentation and analytics. You can find example SQL queries in the `sql/` directory.
